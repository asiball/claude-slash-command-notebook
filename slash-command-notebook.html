Slash Command Notebook

Claude Code(ターミナルで動く Anthropic のコーディングエージェント CLI)では、対話シェルに / で始まる「スラッシュコマンド」を打って機能を呼び出す。本ページはそれらを実際に実行し、「ユーザーの入力」と「Claude の最終出力・画面」のペアを Notebook 形式で記録したもの。対象は公式ドキュメント code.claude.com/docs/en/commands に掲載の全80超のコマンドのうち、よく使う25個。

コマンドは2種類に大別される: プロンプト注入型(コマンドの実体として登録された指示プロンプトがモデルに渡り、出力が返る。Claude Code ではこの仕組みを Skill と呼ぶ)と UI/ハーネス型(CLI 本体=ハーネスが画面上で処理し、モデルは関与しない)。/compact や /recap のように、モデル呼び出しがセッションの外側で行われる中間形も少数ある。前者は §1 で入力と出力を、後者は §2 で端末画面を実測し、§3 に早見表を置く。

§1実行デモ — プロンプトと出力の実測

デモ用サンプルプロジェクト(Python 製の小さな電卓。意図的にバグと脆弱性を仕込んである)に対して claude -p "/コマンド" でヘッドレス実行(対話 UI なしで1回だけ実行するモード)して最終出力を Out に採取した。セルは、プロジェクト立ち上げ→レビュー→カスタムコマンド→セッション操作→環境診断、最後に追補(/verify・/btw)の順。多くのセル末尾に付けた「端末画面(実測)」は対話モードでの別回の実行のため、Out と内容が一致しないことがある。

# Vuln 1: Command Injection: src/user_db.py:18

  • Severity: High / Category: command_injection
  • Description: ping_host() concatenates the host argument directly into a string passed to os.system(), which executes via the shell. Any shell metacharacters in host allow arbitrary command execution.
  • Exploit Scenario: A caller invoking ping_host("8.8.8.8; rm -rf /") causes arbitrary commands to run with the process's privileges.
  • Recommendation: Use subprocess.run(["ping", "-c", "1", host], shell=False) and validate that host matches a legitimate hostname/IP format before use.

# Vuln 2: Authentication Bypass: src/user_db.py:15

  • Severity: High / Category: authentication_bypass
  • Description: login(name, password) never checks name — it only compares password against a single hardcoded constant. Anyone who knows this one value is authenticated as any username, including admin.
  • Exploit Scenario: An attacker calls login("admin", "hunter2") and is authenticated as the admin account regardless of the actual credential-to-user mapping.
  • Recommendation: Store per-user hashed credentials (e.g., bcrypt/argon2) and validate against the specific name's stored hash. Use a constant-time comparison (hmac.compare_digest) instead of ==.

§3早見表 — よく使うコマンド

全80超のコマンドのうち、日常的に使う可能性が高いものに絞った早見表。コマンド一覧はバージョンごとに変わるため網羅はせず、変わりにくい主要なものだけを載せる。Skill 印はプロンプト注入型(§1 で実測)、中間形 印はモデル呼び出しがセッション外で行われるもの(§1 で実測)。UI 印は UI/ハーネス型(§2 で画面実測。/cost のような別名コマンドは単独の画面セルを持たない)。

セッションとコンテキスト

コマンド動作
/clearUI空のコンテキストで新しい会話を開始する。→ §2 で画面実測。
/resumeUI以前の会話一覧から選んで復帰する。→ §2 で画面実測。
/compact [指示]中間形会話を要約してコンテキストを解放する。要約方針を引数で指示できる。→ §1 で実測。
/contextUIコンテキスト使用状況をカラーグリッドで可視化する。→ §2 で画面実測。
/rewindUIコードと会話をチェックポイントまで巻き戻す。→ §2 で画面実測。
/recap中間形セッションの1行サマリーを生成する。→ §1 で実測。
/btw [質問]中間形会話の文脈に残らないサイド質問をする。→ §1 で実測。

取得方法(再現手順)

  • 実行環境: Claude Code CLI v2.1.233 / 2026-08-17 実測。
  • 出力の採取: claude -p "/コマンド" --model <model> のヘッドレス実行の標準出力。
  • UI 型の画面の採取: tmux の仮想端末(110×42)で対話モードを起動し、コマンド実行直後に tmux capture-pane -e -p で ANSI カラー付きテキストとして採取し、256色コードを HTML に変換して表示(実際の端末配色の近似)。メールアドレス・セッションID等は伏せ字に置換。
  • §1 各セルの「端末画面(実測)」: プロジェクトのクリーンコピーに対する対話モード(haiku、同じく tmux 110×42)での別回の実行を採取したもの。プロンプト・出力の記録とは実行回が異なるため、指摘内容や言語が一致しない場合がある(例: 対話実行ではユーザーのグローバル CLAUDE.md の「日本語で回答」が適用される)。
  • 注意: LLM の出力は非決定的であり、ここに載せた出力は「ある1回の実行例」である。また Skill 系コマンドの内部動作は CLI のバージョンにより変わりうる。
