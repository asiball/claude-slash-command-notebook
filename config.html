Config Notebook

同じ入力(依頼文)を固定したまま、設定だけを切り替えると Claude Code の出力・挙動がどう変わるかを実測で記録する。各セルのトグルで設定の有無・値を選ぶと、その設定で採取した画面(Out)に切り替わる。

対象は、切り替えたときの差が目に見えて分かる 4 つのキーに絞った: outputStyle(応答文が変わる)・permissions.deny(実行が拒否される)・permissions.defaultMode(確認の出方が変わる)・sandbox(OS レベルで実行が制限される)。「(未採取)」の枠は後日ローカルで採取して差し替える(取得方法)。

§1設定 × 出力の実測比較

ボタンで設定を切り替えると Out の画面が入れ替わる。各パネルには、その採取で使った settings ファイルの中身(切り替えた部分)を添えてある。画面は tmux の仮想端末(110×42)からの ANSI キャプチャで、モデル応答は非決定的 — ここに載せた出力は「ある1回の実行例」である。

未採取 — ルールがなければファイルは普通に読まれる(はず)。 ローカルで ./capture-config.sh → python3 ansi2html.py config を実行するとこの枠に流し込まれる。

sandbox

未採取(後日ローカルで採取)

作業ディレクトリ外への書き込みが、Bash サンドボックスの有無でどう変わるか。サンドボックス有効時は多くのコマンドが確認なしで走る代わりに、書き込みは作業ディレクトリとセッション temp のみに OS レベルで制限される。

In(共通)❯ touch /tmp/sandbox-poke.txt を実行して

.claude/settings.local.json

{ "model": "claude-haiku-4-5" }
claude — sandbox: off (touch /tmp)
(未採取)

未採取 — manual の確認ダイアログに Yes と答えると普通に成功する(はず)。 ローカルで ./capture-config.sh → python3 ansi2html.py config を実行するとこの枠に流し込まれる。

.claude/settings.local.json

{ "model": "claude-haiku-4-5", "sandbox": { "enabled": true } }
claude — sandbox: on (touch /tmp)
(未採取)

未採取 — 既定(autoAllowBashIfSandboxed: true)では確認なしでサンドボックス内実行され、/tmp への書き込みが OS にブロックされて違反詳細付きで失敗する(はず)。失敗を見た Claude が dangerouslyDisableSandbox での再試行を提案することがある。 ローカルで ./capture-config.sh → python3 ansi2html.py config を実行するとこの枠に流し込まれる。

前提: macOS は組み込みの Seatbelt で追加インストール不要。Linux / WSL2 は bubblewrap と socat が必要(/sandbox パネルの Dependencies タブで確認できる)。

取得方法(再現手順)

  • 採取日: 2026-08-23。Claude Code 2.1.241(macOS、Claude Max アカウント)。モデルはフィクスチャの local 設定(claude-haiku-4-5)、outputStyle 比較と auto モードのみ --model sonnet。
  • 採取は ./capture-config.sh: work/config-demo に Setup のフィクスチャを構築し、セルごとに .claude/settings.local.json(deny 比較のみ settings.json)を書き換えて別セッションを起動し、tmux の仮想端末(110×42)から採取する。~/.claude のユーザー設定には触れない。
  • 採取後、python3 ansi2html.py config で本ページの枠を実測キャプチャに差し替える(term-bar のラベルで枠を特定する。「(未採取)」の枠は初回に全行が流し込まれ、以降は既存の先頭行・末尾行を境界に置換)。メールアドレス・セッション ID・ホームディレクトリのパスは同スクリプトで伏せ字化。
  • sandbox セルの採取前提: macOS は追加インストール不要(Seatbelt)。Linux / WSL2 は bubblewrap と socat が必要。
  • 「実測:」は採取した画面から読み取った内容。「(はず)」と書いた挙動は公式ドキュメント(2026-08-24 参照)に基づく想定で、採取後に実測へ置き換える。
