Config Notebook

同じ入力(依頼文)を固定したまま、設定だけを切り替えると Claude Code の出力・挙動がどう変わるかを実測で記録する。各セルの Config の選択肢を押すと、その設定で採取した画面(Out)に切り替わる。

対象は、切り替えたときの差が目に見えて分かる 4 つのキーに絞った: outputStyle(応答文が変わる)・permissions.deny(実行が拒否される)・permissions.defaultMode(確認の出方が変わる)・sandbox(OS レベルで実行が制限される)。採取手順は取得方法。

work/config-demo/

採取用フィクスチャ · capture-config.sh が毎回再構築

各セルの採取はこの最小フィクスチャに対して行う。切り替える設定はセルごとに書き換え、別セッションで起動し直して採取する。

work/config-demo/
├── src/hello.py                # print("hello from config-demo") のみ
├── private/credentials.env     # ダミー値 DUMMY_TOKEN=xxxx
└── .claude/
    ├── settings.json           # { "model": "claude-sonnet-5", "permissions": {...} }
    └── settings.local.json     # { "model": "claude-haiku-4-5" } を基点にセルごとに書き換え
  • .claude/settings.json — プロジェクト共有(git 管理)。チームで揃えたい deny などのルール向き → deny の比較はこちらを切り替える。
  • .claude/settings.local.json — 個人用(gitignore)。outputStyle / defaultMode / sandbox の比較はこちらを切り替える。
  • 優先順位: CLI 引数(--model など)> settings.local.json > settings.json > ~/.claude/settings.json。local に haiku を置いたまま --model sonnet で起動すれば sonnet になる(画面の応答モデル名がその結果)。

§2次にやること

自分の環境で試すなら、プロジェクトの .claude/settings.local.json に必要なキーだけ書いて Claude Code を起動し直す(outputStyle はセッション開始時に固定される)。上の 4 セルを 1 つにまとめると:

{
  "outputStyle": "Concise",
  "permissions": {
    "defaultMode": "acceptEdits",
    "deny": ["Read(./private/**)"]
  },
  "sandbox": { "enabled": true }
}
  • キーの一覧と優先順位は公式 docs: Settings · Permissions · Sandboxing
  • 対話中に切り替えるなら /config(outputStyle)・/permissions(allow / deny)・shift+tab(権限モード)・/sandbox。画面は姉妹ページの /config・/permissions セル。

取得方法(再現手順)

  • 実測日 2026-08-24、Claude Code CLI v2.1.241(WSL2 / Ubuntu、Claude Max アカウント)。モデルはフィクスチャの local 設定(claude-haiku-4-5)、outputStyle 比較と auto モードのみ --model sonnet。
  • 採取は ./capture-config.sh: work/config-demo に Setup のフィクスチャを構築し、セルごとに設定ファイルを書き換えて別セッションを起動し、tmux 仮想端末(110×42、outputStyle 比較は 110×60)の ANSI 出力を python3 ansi2html.py config で HTML 化して差し替える(index.html と同じ方式)。~/.claude のユーザー設定には触れない(マシン固有の statusLine 表示だけ --settings で空に上書き)。
  • 実行系の画面は応答後に ctrl+o の詳細トランスクリプト表示に切り替えて採取(通常表示ではツールの結果・拒否エラーが畳まれるため)。権限モードのフッターは起動直後の下 4 行だけを切り出した。
  • メールアドレス・セッション ID・ホームディレクトリのパス・採取マシンのユーザー名は伏せ字化。
  • sandbox あり側の前提: macOS は追加インストール不要(Seatbelt)。Linux / WSL2 は bubblewrap と socat が必要(/sandbox パネルの Dependencies タブで確認できる)。
